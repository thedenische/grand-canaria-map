# Гран-Канария — карта интересных мест

Публичная интерактивная карта интересных мест острова Гран-Канария.

**Карта:** https://thedenische.github.io/grand-canaria-map/

## Содержимое

- `index.html`, `styles.css`, `app.js` — веб-карта на Leaflet.
- `data/places.json` — каталог точек с координатами, описаниями и оценкой пригодности для посещения с ребёнком.

## Локальный запуск

Откройте репозиторий через любой статический HTTP-сервер из корня проекта, например:

```bash
python3 -m http.server 8000
```

Затем перейдите на http://localhost:8000.

Карта использует Leaflet и тайлы OpenStreetMap. Детские оценки носят ориентировочный характер; перед посещением проверяйте погоду, доступность и актуальные ограничения.
